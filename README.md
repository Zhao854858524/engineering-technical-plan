# 工程技术方案编写

本仓库用于沉淀和编写工程技术方案文档，包含标准编写模板与成果文件。

## 目录说明

- `工程技术方案编写模板.md` —— 通用工程技术方案标准模板（可直接复制套用）
- `方案成果/` —— 存放编写完成的具体工程技术方案

## 使用方法

1. 复制 `工程技术方案编写模板.md` 到 `方案成果/` 目录；
2. 按项目实际信息填充各章节内容；
3. 编写完成后提交入库，提交消息格式建议：`docs: 新增/更新 <项目名> 技术方案`。

## 编写规范

- 章节结构不得随意删减，可按项目特点增补；
- 引用规范必须写明标准编号与名称（如 GB 50300-2013）；
- 方案定稿前须经技术负责人审核签字。
